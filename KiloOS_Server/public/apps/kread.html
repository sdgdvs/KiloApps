❓ KRead User & Keyboard Guide

Keyboard Shortcuts:

  • F1 or H - Open this Help Dialog
  • Ctrl + O - Open Document(s)
  • Ctrl + T - Open a New Tab
  • Ctrl + W - Close Active Tab
  • Ctrl + Tab / Ctrl+Shift+Tab or [ / ] - Next / Previous Tab
  • Ctrl + 1-9 - Switch to Tab 1 through 9
  • F2 - Rename Active Tab
  • Ctrl + F or / - Find Text in Document
  • Ctrl + B - Quick Add Bookmark
  • B / N / O - Toggle Bookmarks / Notes / Outline Drawer
  • Alt + S - Launch RSVP Speed Reader
  • A - Toggle Hands-Free Auto-Scroll
  • M - Toggle Formatted Markdown vs. Raw Text View
  • T - Cycle Reading Theme (Light/Dark/Sepia/Contrast)
  • Ctrl + Shift + C - Copy Entire Document Text
  • Del - Clear Active Document
  • Space / Shift+Space - Page Scroll Down / Up
  • J / K or ↓ / ↑ - Line Scroll
  • Home / End - Jump to Document Start / End
  • Ctrl + S - Open Reading Statistics
  • + / - - Zoom Font Size (or adjust auto-scroll speed)
  • F5 - Snapshot Quicksave Complete Workspace State
  • F9 - Snapshot Quickload Complete Workspace State
  • Shift + M - Toggle Procedural YM2612 FM Audio & SPC700 Delay
  • 0 - Reset Font Size to Default (18px)
  • Esc - Close Panels, Drawers, & Modals / Stop Auto-Scroll

Advanced E-Reader Capabilities:

  • Document Outline & TOC: Automatic heading extraction with clickable navigation tree.
  • RSVP Speed Reader: Rapid Serial Visual Presentation with optical fixation highlighting and 120-900 WPM pacing.
  • Hands-Free Auto-Scroll: Smooth continuous reading with variable speed and auto-pause on wheel/hover.
  • Formatted Markdown Mode: Rich reader rendering for headers, lists, blockquotes, and code blocks with 1-click copy.
  • Multi-Tab Global Search: Cross-tab search index with hit counters and 1-click jump.
  • Data Interoperability: Import/export annotations (JSON/Markdown/TXT) and full multi-tab workspace sessions.
  • Quick Load Presets: Instant 1-click loading for Cyberpunk, Time Machine, KiloOS, Alice, and Chronos '99.
