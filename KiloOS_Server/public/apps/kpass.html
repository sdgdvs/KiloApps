KPass Help & Shortcuts

Generator: 4 modes: Random characters, Memorable Passphrase (Diceware), PIN code, or Hex key. Click password display to quickly copy.

Vault: Secure credentials vault with Username, Password, Notes, and Category tracking encrypted locally using AES-GCM 256 with PBKDF2 (100,000 rounds).

Security Audit: Real-time health scanner detecting weak passwords, reused credentials across accounts, and stale entries (>90 days).

Interoperability: Multi-format export to CSV, JSON, formatted Markdown (.md), and encrypted portable backup (.kpass).

Auto-Lock: For your security, the vault auto-locks after 1 minute of inactivity.

Shortcuts:
• '1' = Generator | '2' = Vault | '3' = Security Audit | 'H' / F1 = Help
• F5 = Quicksave snapshot | F9 = Quickload snapshot
• Enter = Unlock / Save / Generate | Ctrl+F or '/' = Focus Search
• Ctrl+S = Save Credential | Ctrl+G = Generate | Ctrl+C = Copy Password
• Alt+L = Lock Vault | Alt+J = JSON | Alt+E = CSV | Alt+M = Markdown | Alt+I = Import
