KChat Server - Architecture & Operations Manual

Network Architecture & Dual Protocols

KChat Server hosts multi-client TCP chat rooms for KChat peers on LAN or WAN networks with dual-stack support:

  • WebSocket RFC 6455: Web-based KChat clients handshake via HTTP/1.1 101 Switching Protocols with SHA-1 key verification.
  • Raw TCP WinSock: Native clients exchange newline-terminated ASCII packets directly on the configured port.
  • Broadcast Console: Transmit system-level announcements across individual channels or globally to all connected peer slots.
  • Client Telemetry: Monitor active sockets, peak connections, packet telemetry, bandwidth counters, and ping latency in real-time.

Keyboard Shortcuts & Operational Controls

  • S — Start / Stop server daemon
  • B — Focus System Broadcast Console input
  • Enter — Transmit broadcast announcement (when focused)
  • F5 — QuickSave server state and telemetry to local storage
  • F9 — QuickLoad server state and telemetry from local storage
  • C — Copy connection string (IP:Port) to clipboard
  • L — Clear console output buffer
  • F1 — Toggle this Operations Manual
  • Esc — Dismiss open dialog
