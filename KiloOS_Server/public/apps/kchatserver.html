Native Desktop Companion

KChat Server

KChat Server is a high-performance native Win32/WinSock application designed to run outside the web browser sandbox for multi-user chat hosting.

  1. Click the Download Native Exe button in the titlebar.
  2. Run KChatServer.exe on your Windows host machine.
  3. Specify a port (default: 6667) and click Start Server.
  4. Share your IP address with peers to connect via KChat.
