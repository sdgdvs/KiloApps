❓ KTodo Help & User Guide

⌨️ Keyboard Shortcuts

  • Enter (in Task field): Add task immediately
  • N: Focus task input to quickly create new task
  • / or F: Focus search input
  • ↑ / ↓: Navigate and select tasks in list
  • Space: Toggle completed on selected task
  • Delete: Delete selected task
  • 1 / 2: Switch between List and Kanban views
  • O: Open Live Team Collaboration dialog (Firebase RTDB)
  • W: Switch to next multi-tab Workspace
  • S: Toggle productivity statistics
  • I: Open Import / Export dialog (Markdown, CSV, JSON, Todo.txt, iCal)
  • C: Clear completed tasks
  • F5: Quicksave workspace snapshot to localStorage
  • F9: Quickload restored workspace snapshot
  • F1 or H: Open / close this Help guide
  • Escape: Close active modal or clear search

🚀 Task Management & Features

  • • 🌐 Live Team Collaboration: Connect via Firebase RTDB in real time across computers on kiloapps.web.app without servers.
  • • 📁 Multi-Tab Workspaces: Switch between distinct project boards (Default, Sprint 1999, Personal, SysAdmin) or add custom ones.
  • • 🏷️ Dynamic Hashtags: Type #tag in tasks; click tags in the tag bar to filter instantly.
  • • ⚡ Batch Actions: Mark all visible tasks done, set priorities, or re-categorize in bulk.
  • • Views: Toggle between detailed List view and Kanban board (To Do, In Progress, Done).
  • • Categories & Priorities: Work, Personal, Project, Health, Shopping with High/Med/Low badges.
  • • Checklists: Click 📋 on any task card to expand and add subtasks.
  • • Edit Tasks: Click ✏️ or double-click any task title to edit in-place.
  • • Data Interoperability: Import and export Markdown checklists, CSV spreadsheets, JSON backups, Todo.txt, and iCalendar (.ics).

✨ Welcome to KTodo

Your sovereign, zero-bloat productivity workstation. Here is everything you need to know:

⚡ 1. Rapid Task Capture [N & Enter]

Press N to focus input, enter task details, and hit Enter to capture immediately.

📋 2. Dual Views: List [1] & Kanban [2]

Switch between high-density nested checklists (1) and three-column Kanban boards (2).

💾 3. State Persistence [F5 & F9]

Press F5 to snapshot tasks, categories, filters, and views. Press F9 to restore. Auto-session recovery protects data on reloads.

📦 4. Markdown & Backups [I]

Press I to import/export standard GFM Markdown task lists, JSON snapshots, or CSV sheets.

🌐 Live Team Collaboration (Firebase RTDB)

Collaborate in real time with team members anywhere on kiloapps.web.app. Tasks, checkmarks, subtasks, and edits synchronize instantaneously across computers.
