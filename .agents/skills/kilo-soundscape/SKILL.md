## Composition Architecture (MANDATORY for Every Track)

All music must implement the following architecture. Generic 8-step loops that only play bass and
a single melody line are **not acceptable**.

### Channel Budget (6 logical channels in Web Audio)
| Channel | Role | Behavior |
|---|---|---|
| **Ch1: Lead Melody** | Primary theme voice | Vocal-style phrasing; rests every 4–8 bars; delayed vibrato (wait 200ms then ramp up) |
| **Ch2: Counter-melody** | Contrary motion to Lead | Active when Lead sustains; moves in opposite direction |
| **Ch3: Harmony / Arpeggio** | Shell voicing or rapid arpeggio | Fills harmonic gaps; runs when Lead rests |
| **Ch4: Bass** | Active, melodic counterpoint | Root/octave motion below C3; stepwise motion in C3–C4 |
| **Ch5: Percussion** | Kick + Snare | FM-synthesized; swing groove (see §5) |
| **Ch6: Hi-hat / FX** | Cymbal wash / SFX triggers | Inharmonic FM (MUL ratios 9/11/13/15) |

### Voice-Leading Rules (CRITICAL — Violations Make Music Sound Generic)
1. **Contrary motion**: If Lead ascends, Bass/Counter must descend. Never parallel motion on all voices simultaneously.
2. **Shell voicings only**: Bass = Root. Upper voices = 3rd + 7th (or 6th). **Never double the 5th.**
3. **Frequency separation**: No thirds or complex intervals below C3 (MIDI 48). Bass register uses only roots, 5ths, and octaves.
4. **Call-and-response**: When Lead is active, Counter sustains. When Lead rests (1–2 bars), Counter takes melodic spotlight.
5. **Suspensions on weak beats**: Place 7ths and 9ths on off-beats; resolve stepwise on next downbeat.

## FM Patch Design Reference

### playFmTone() Signature
All synthesis uses the existing `playFmTone(carrierFreq, modRatio, modIndex, duration, gainVal, useEcho)` pattern. Create named patch functions wrapping this:

```javascript
// Example: Electric Rhodes/DX7-style piano patch (Algorithm 2 analog)
// Modulator decays fast → bright attack, mellows to warm fundamental
function playEPiano(freq, dur, vol) {
  const now = audioCtx.currentTime;
  const carrier = audioCtx.createOscillator();
  const modulator = audioCtx.createOscillator();
  const modGain = audioCtx.createGain();
  const ampEnv = audioCtx.createGain();
  carrier.type = 'sine'; modulator.type = 'sine';
  carrier.frequency.setValueAtTime(freq, now);
  modulator.frequency.setValueAtTime(freq * 2.0, now);          // MUL ratio 2:1
  modGain.gain.setValueAtTime(freq * 2.0 * 2.8, now);           // modIndex 2.8 = bright attack
  modGain.gain.exponentialRampToValueAtTime(freq * 0.15, now + 0.08); // fast mod decay → mellow
  modGain.gain.exponentialRampToValueAtTime(0.01, now + dur);
  ampEnv.gain.setValueAtTime(vol, now);
  ampEnv.gain.exponentialRampToValueAtTime(0.001, now + dur);
  modulator.connect(modGain); modGain.connect(carrier.frequency);
  carrier.connect(ampEnv); ampEnv.connect(audioCtx.destination);
  if (snesDelayNode) ampEnv.connect(snesDelayNode);
  modulator.start(now); carrier.start(now);
  modulator.stop(now + dur); carrier.stop(now + dur);
}
```

## Chord Progressions by Genre

### Royal Road (Ōdō Shinkō) — JRPG / Town / Overworld
`IV – V – iii – vi` — In C: F → G → Em → Am
- Bypasses tonic I, lands on iii (bittersweet minor-ish feel). Loop endlessly.

### Mario / Heroic Cadence — Boss Victory / Action
`♭VI – ♭VII – I` — In C: A♭ → B♭ → C
- Borrows from parallel minor. Triumphant whole-step bass lift.

### Andalusian Descent — Dungeon / Horror / Dark
`i – ♭VII – ♭VI – V(7)` — In Am: Am → G → F → E(7)
- Stepwise descending bass, Phrygian half-step pull into major V.

### Pedal + Modal Mixture — Space / Sci-Fi
Lydian pedal tone (♯4 in scale) with floating Maj9 chords. No percussion mandatory.

### Suspended Cascade — Underwater / Calm
`sus2 → Maj7 → sus4 → Maj9` — pillowy movement, no strong V–I resolutions.

## Swing Groove (Mandatory for Rhythm Tracks)

Standard setInterval BGM ticks at constant ms = no groove. Implement alternating step durations:

```javascript
// Swing 2:1 (jazz/funk shuffle): long-short-long-short
// Even steps: 180ms, Odd steps: 90ms → 6:3 = 2:1 ratio
// Subtle house swing: Even 175ms, Odd 105ms → 5:3 ratio

let bgmStep = 0;
function scheduleBgmStep() {
  const isEven = (bgmStep % 2 === 0);
  const nextDelay = isEven ? 175 : 105;  // subtle 5:3 swing
  playBgmStep(bgmStep);
  bgmStep++;
  bgmTimer = setTimeout(scheduleBgmStep, nextDelay);
}
```

## SPC700-Style Echo (SNES Delay DSP)

The existing shared `snesDelayNode` (180ms, LP filter at 2200Hz, feedback 0.28) is already wired.
Use it selectively:
- **Lead melody and counter**: `useEcho = true` → adds spatial depth
- **Bass and kick**: `useEcho = false` → keeps low end tight and punchy
- **Pad/ambient**: `useEcho = true` with higher feedback for cavernous effect

## Per-Genre Audio Identity Guide

### Dungeon / Roguelike (KRogue, KMaze, KAbyss)
- **Mode**: Phrygian (A: A–B♭–C–D–E–F–G) or Aeolian with ♭2
- **Progression**: Andalusian descent (Am → G → F → E)
- **Texture**: Sparse. Long rests. Staccato "water drip" lead (hollow flute FM patch, short notes with gaps)
- **Bass**: Root-only, very slow, sustained
- **Percussion**: None mandatory; optional quiet kick every 4 bars
- **Echo**: Maximum feedback, long tail

### Space / Sci-Fi (KSpace, KStarForge, KStellar, KAbyss)
- **Mode**: Lydian (♯4 = celestial wonder) or Whole-tone
- **Progression**: Floating Maj9 / sus2 chords; pedal drone in bass
- **Texture**: Metallic bell lead, wide-pan pad sustain, high arpeggio glitter
- **Bass**: Sub-bass pad drone (modRatio 0.5), slow attack
- **Percussion**: Soft – rim-shot style snare, no hard kick
- **Echo**: Ping-pong stereo (alternate left/right timing)

### Combat / Boss (KColosseum, KFortress)
- **Mode**: Phrygian Dominant (♭2, ♮3) or Harmonic Minor
- **Progression**: i → ♭VII → ♭VI → V (speed-up each iteration)
- **Texture**: Distorted FM guitar lead, galloping 16th bass (Root–Root–Octave), aggressive chord stabs off-beats
- **Bass**: Slap bass FM patch, punchy transients
- **Percussion**: Tight kick + snare, 16th hi-hats, fill every 4 bars
- **Echo**: Minimal (dry combat feel)

### Underwater (KSubmarine)
- **Mode**: Major pentatonic cascades; sus2 and sus4 chords; whole-tone runs
- **Progression**: No strong cadences; float between IV and I (plagal)
- **Texture**: Muffled pad lead (low LP filter on echo return), slow vibrato, no hard attack
- **Bass**: Stripped of click transients (modIndex near zero = warm sine)
- **Percussion**: None; or very soft brushed snare (fast decay, low volume)
- **Echo**: High feedback, slower delay (250ms)

### Adventure / Overworld (KRogue surface, KQuest, KWizard)
- **Mode**: Major with Mixolydian ♭7 mix
- **Progression**: Royal Road (IV–V–iii–vi) → repeat; Mario Cadence for phrase endings
- **Texture**: E-Piano lead with counter-melody, walking bass, light hi-hats
- **Percussion**: Kick on 1+3, snare on 2+4, off-beat hi-hat 16ths

### Retro / Chiptune (KPac, KAsteroids, KBreakout, KSnake)
- **Mode**: Major pentatonic or straight Ionian
- **Progression**: I–IV–V–I (simple), speed up for tension
- **Texture**: Square-wave-ish FM lead (modRatio 1.0, modIndex 2.0 → sawtooth-like), no pad
- **Percussion**: Punchy kick+snare, tight hi-hat 8ths
- **Echo**: Minimal

## Implementation Steps (Per Turn)

1. **Read** the existing audio section of the target file. Identify what's there (how many tracks, how the BGM loop works, what frequencies/patterns are used).
2. **Assess** what's inadequate: Is it a 2-line bass loop? Single-oscillator melody only? Generic presets?
3. **Design** the composition: Pick genre from §Per-Genre Guide, pick progression, plan 3-voice layout.
4. **Implement**:
   - Write named FM patch functions (at least 2–3 unique timbres per track)
   - Write melody/counter/bass note arrays using proper frequency tables (see §Note Frequencies)
   - Replace `setInterval` BGM loop with swing-tick `setTimeout` chain
   - Wire SPC700 echo selectively (lead on, bass off)
   - Add `[M]` mute toggle and audio toggle button if not present
5. **Earcons**: Replace any generic `playFmTone(600, 2.0, 1.2, 0.04)` click-beeps with context-appropriate SFX using named patches.
6. **Virtual web destinations**: Also review the on-screen track name/description and update it to match the new composition's character.
