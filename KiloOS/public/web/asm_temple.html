1. DOS MZ Header (IMAGE_DOS_HEADER)

The 64-byte legacy header retained for backwards compatibility with MS-DOS 2.0+
Every valid 32-bit Win32 executable begins with the legacy IMAGE_DOS_HEADER (64 bytes).

• e_magic: Must equal 0x5A4D ("MZ", named after Mark Zbikowski).
• e_lfanew: Located at offset 0x3C (4 bytes). Holds the file pointer offset to the true NT PE Header. If this pointer is corrupted, the Win32 OS loader halts immediately with "Invalid Win32 Application".
🛡️ The Rings of Protection (x86 CPU Privilege Hierarchy)
• Ring 0 (Supervisor / Kernel Space): Direct access to CPU control registers (CR0, CR3, CR4), I/O ports (IN / OUT), Interrupt Descriptor Table (IDT), and page tables. All drivers and NT kernel run here.
• Ring 3 (User Space / Applications): Restricted memory sandbox. Direct hardware port instructions fault with EXCEPTION_PRIV_INSTRUCTION. All Win32 programs request OS services through transition gates (e.g. SYSENTER or INT 2Eh).
