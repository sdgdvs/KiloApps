🎓 KTerm Quick-Start Briefing & Architecture
🖥️ Welcome to KTerm: Advanced retro shell emulator for KiloOS featuring multi-tab sessions, pipeline redirection, VFS virtual file manipulation, safe math evaluation, and persistence state management under strict <999 KB constraints.
🚀 Core Features & Workflow
Ctrl + T / Ctrl + WManage up to 8 isolated terminal sessions with independent working directories, histories, aliases, and environment variables.
> / >> PipingRedirect terminal tool output directly to VFS files (e.g. help > manual.txt or ps >> logs.txt).
; & && ChainingExecute sequential batches of commands in a single line (e.g. uptime ; dir ; ver).
F5 / F9 HotkeysF5 Quicksave snapshots all open tabs, histories, and macros to localStorage. F9 Quickload restores session state instantly.
Ctrl + R SearchIncremental reverse search through command history buffer with live match completion.
calc <expr>Built-in recursive-descent arithmetic calculator with parentheses and operator precedence without eval.
⚡ Quick Tips
  • Double-click any tab in the header bar to quickly rename it.
  • Click any command row in the Help (F1) reference or any chip in the Quick Bar to execute it immediately.
  • Cycle between 6 CRT phosphors anytime using the 🎨 Theme button or theme <name> command.
  • Export full JSON snapshots via 📦 Backup and reload them anytime using 📂 Restore (Ctrl+O).
