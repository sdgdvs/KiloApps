🔍 1. Hardware Inspector & Health Index

Displays live hardware specifications, CPU load spectrum across all cores, System Health & Anomaly Index, WebGL GPU graphics, storage quotas, and socket/network telemetry.

⚡ 2. Diagnostic Benchmarks

Executes multi-threaded CPU matrix stresses, 64MB RAM read/write bandwidth checks, and IndexedDB disk storage I/O throughput tests.

⚙️ 3. Services & Telemetry

Monitors real-time CPU load and JS Heap memory with live sparklines. Features granular regex filtering, status filters, and custom daemon registration.

📋 4. Event Logs & 💾 5. Report Export

Track system lifecycle logs with regex search, manage persistent Quicksave snapshots (F5/F9), import JSON audits (I), and export detailed reports in TXT, JSON, HTML, CSV, or Markdown.

🔬 6. Memory & Hex Buffer Inspector

Live hexadecimal and ASCII inspection of system state buffers, hardware structures, and diagnostic heap frames with byte search, offset jumping, and .HEX/.BIN export.
