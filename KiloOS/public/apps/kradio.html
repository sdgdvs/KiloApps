📻 KRadio Player Guide

KRadio streams live synthwave, ambient, lo-fi, and internet radio stations in real time inside KiloOS with HiDPI retro spectrum visualization and 3-band DSP equalizer.

Space / P Toggle Play / Pause stream
S Stop audio stream
F5 Quicksave active station & playback state
F9 Quickload restored session & playback
1 – 6 Quick tune station preset
Shift + 1 – 6 Assign current stream URL to preset slot
← / → Cycle previous / next preset
E Toggle 3-Band DSP Equalizer panel
B Open Curated 1999 Station Directory
T Cycle Sleep Timer (15m, 30m, 45m, 60m, Off)
D Toggle Stream Diagnostics HUD
M Mute / Unmute audio output
↑ / ↓ Adjust volume up / down (+/- 5%)
V Cycle visualizer style (LED / CRT / VU)
Alt + E Export playlist [.json]
Alt + M Export Winamp Playlist [.m3u]
Alt + P Export Shoutcast Playlist [.pls]
Alt + I Import playlist config [.json, .m3u, .pls]
Enter Tune to custom URL in text box
F1 / ? / H Toggle this Help guide
Esc / Space / Enter Dismiss Help guide

Tip: Direct HTTPS MP3 and AAC streaming endpoints are supported. Custom streams can be assigned to any preset slot.
