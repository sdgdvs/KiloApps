🛠️ Feature Modules
  • [1] Converter & Inspector: Real-time synchronization across Hex, Dec, Bin, Oct, ASCII, and IEEE 754 float/double. Includes an interactive 32-bit bitfield manipulator and quick presets (including Project Echo Sector 0x10199904).
  • [2] Hex Editor & Viewer: 16 bytes/row hex viewer and inline byte editor with offset navigation, Jump to Offset, +/-16B step controls, Project Echo ROM memory dump loader (Offset 0x0024), file import, and quicksave/quickload.
  • [3] Entropy & Dissection: Chunked sliding-window entropy heatmap with click-to-jump, Shannon Entropy meter, bit density ratio, byte frequency distribution, and full PE32 Portable Executable Header & Section Dissector (MZ DOS Header, COFF File Header, Optional Header, and Section Tables).
  • [4] Search & Replace: Fast ASCII and Hex byte sequence finder with replace-all capability.
  • [5] Checksum & Hashes: Instant 8/16/32-bit sums, XOR8, CRC-16 CCITT, IEEE CRC32, Adler-32, FNV-1a, MD5, and SHA-256 digests.
  • [6] Byte Operations: Bitwise NOT/XOR/AND/OR, shifts (<</>>), rotations (ROL/ROR), arithmetic add/sub, ASCII case conversions, word endian swaps, and buffer reversal.
  • [7] Data Export: Formatted HexDump, C/C++ array, Intel HEX (.hex), NASM Assembly DB directives, JSON byte array, Rust byte slice, C# byte array, Python bytes, Base64, and RAW file download.
  • [8] Strings & Diff: String Carver & Extractor (ASCII & UTF-16LE with min-length and search filtering), Multi-Segment Binary Difference & Delta Analyzer (Hunk breakdown, mutation types, and byte-by-byte inspection), and Binary Patch Builder & Applier (IPS ROM patch format, DOS DEBUG scripts, C array deltas, and JSON deltas).
  • [9] Opcode Disassembler: Multi-architecture CPU instruction decoder supporting x86-32 Protected Mode, x86-16 Real Mode (DOS .COM), MOS 6502 (NES/C64), and Zilog Z80 (Game Boy/ZX Spectrum), with address rebasing and copy/export to .ASM.
⚡ Welcome to KHex Suite

KHex is an advanced 1999-era binary data inspector, hex editor, Shannon entropy analyzer, and byte manipulation workbench.

🚀 Quick Start Guide
  • Tab 1 (Converter & Inspector): Instant sync across Hex, Dec, Bin, IEEE 754 Float, and 32-bit bitfield manipulator.
  • Tab 2 (Hex Editor & Viewer): 16 bytes/row hex view with inline byte editing, jump-to-offset, and ROM dump inspector.
  • Tab 3 (Entropy & Dissection): Shannon entropy meter, byte distribution histogram, and file magic signature detection.
  • Tabs 4-7: Pattern Search/Replace, Checksums (CRC32/MD5/SHA256), Bitwise Ops, and multi-format Export.
  • Tabs 8-9: String Carver & Binary Diff, Opcode Disassembler (x86, 6502, Z80).
  • 🛰️ Subsystem Memory Offset: Load the Echo ROM sector to inspect classified offset 0x0024!
Hotkeys: [F1] / [H] Help • [1-9] Switch Tabs • [E] Swap Endian • [F5] / [F9] Quicksave/Load • [P] Cycle Presets
