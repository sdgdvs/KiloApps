⚡ KHex Utility Suite — Help & Documentation
Overview: KHex is a comprehensive binary data inspector, base converter, byte manipulation tool, and Shannon Entropy analyzer.
⌨️ Keyboard Shortcuts

[Esc]Dismiss Help Modal / Active Overlays

🛠️ Feature Modules
  • [1] Converter & Inspector: Real-time synchronization across Hex, Dec, Bin, Oct, ASCII, and IEEE 754 float/double. Includes an interactive 32-bit bitfield manipulator.
  • [2] Hex Viewer & Buffer: 16 bytes/row hex viewer with offset mapping, ASCII column, custom file import, and sample data generator.
  • [3] Entropy & Dissection: Shannon Entropy randomness meter, bit density ratio, byte frequency distribution histogram, and file magic signature detection.
  • [4] Search & Replace: Fast ASCII and Hex byte sequence finder with replace-all capability.
  • [5] Checksum & Hashes: Instant 8/16/32-bit sums, XOR8, IEEE CRC32, MD5, and SHA-256 digests.
  • [6] Byte Operations: Invert, XOR mask, buffer fill, word endian swaps, and reversal.
  • [7] Data Export: Formatted HexDump, C/C++ array, Python bytes, Base64, and RAW file download.
