Survival Guide (H / Esc to close)

Controls & How to Play

WASD / Arrows: Move Explorer
Space / [Space] Button: Use EMP Charge (Stuns nearby entities)
F / [F] Button: Deploy Distress Flare (Creates illuminated safe zone that repels lurkers)
F1 / H / Esc: Toggle / Close Survival Guide
F5 / Quicksave: Quicksave State • F9 / Quickload: Quickload State
Export / Import: Backup or restore game state to/from JSON files
R / Enter / Space: Restart (when game over)
Navigate derelict decks (1 to 5), locate access keys and escape pods. Maintain Oxygen and Flashlight Battery. If either runs dry, life support terminates.

Station Hardware & Resources

Security Keycards [Red / Green / Blue]: Unlock color-coded bulkhead blast doors.
Mainframe Terminals: Override remote security locks and access classified telemetry logs.
O2 Rebreather Cylinder (Cyan): Pressurized life-support tank; restores +35% Oxygen.
Lithium Power Cell (Gold): High-capacity capacitor pack; restores +40% Battery.
Survival Lockers: Conceal inside to evade detection from pursuing entities.
Distress Flare [F]: Illuminates a wide perimeter and deters aggressive organisms for 25s.

Entity Bestiary

Stalker (Violet): Agile chitinous hunter. Sensitive to movement and sound. Lethal contact.
Phantom (Cyan, Deck 2+): Electromagnetic phase organism. Shimmers invisibly in darkness until exposed to direct flashlight or flare light.
Bloater (Green, Deck 3+): Sluggish toxic carrier. Discharges puddles of corrosive bio-acid that breach suit integrity (-5% O2).
Apex Behemoth (Crimson, Deck 4-5): Armored dread bio-titan. Tremors announce its approach. Resists EMP disruption (short stun).
