ℹ️ KJournal User Guide & Shortcuts

Keyboard Shortcuts:

  • F1 or H — Open this Help guide
  • Ctrl + S — Save current journal entry immediately
  • Ctrl + N — Jump to today's entry
  • Ctrl + P — Toggle Markdown Preview mode
  • Alt + P — Insert Random Reflective Inspiration Prompt
  • Ctrl + B / Ctrl + I — Bold / Italic formatting
  • Alt + Left / Right — Navigate to previous / next calendar day
  • Alt + C or Ctrl+Shift+C — Copy active journal entry to clipboard
  • Ctrl + T — Open Prompt Templates Library
  • Ctrl + I — Open Data Import / Export modal
  • Ctrl + F — Focus Search & Hashtag filter bar
  • Alt + 1..6 (or 1..6) — Select Mood (Happy, Calm, Neutral, Sad, Energetic, Focused)
  • Delete — Delete current entry (when editor is unfocused)
  • Esc — Close active dialog / modal or clear search

Core Features:

  • Multi-Notebook Categories: Organize entries into Personal, Work, Ideas, Dreams, and Health.
  • Live Markdown Preview & Split View: Write with headings, blockquotes, and checkboxes with real-time rendering.
  • Formatting Toolbar: One-click buttons to insert headings, task checkboxes, lists, quotes, and timestamps.
  • Quick Mood Filter: Filter journal history instantly by mood in the sidebar.
  • Rich Data Exports: Export to JSON, CSV (spreadsheets), Markdown, TXT, and printable HTML chronicle.
  • Toolbar Day Navigator: Move between days with ◀ / ▶ buttons or jump straight to today.
  • Calendar Navigator: Pick any day from the visual monthly grid to review or edit entries.
  • Guided Prompts & Templates: Click '📋 Templates [^T]' to choose from 6 structured frameworks.
  • Daily Inspiration: Click '💡 Daily Prompt [Alt+P]' for 25+ curated self-reflection prompts.
  • Interactive Daily Word Goal: Click the goal progress bar in the footer or adjust in Settings.
  • Real-time Search & Hashtags: Use hashtags (e.g. #gratitude #goals) to categorize and filter.
  • Analytics & Streaks: Track current streak, best streak, total words, keywords, and mood breakdown charts.
  • PIN Lock Protection: Secure your personal entries with a 4-digit numeric PIN in Settings.
