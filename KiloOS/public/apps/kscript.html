⚡ KScript Guide & Shortcuts

KScript is a lightweight, high-performance scripting language and expression evaluator.

Syntax & Features

  • Variables: Single-letter variables a through z (e.g. x = 42).
  • Math Operators: Addition +, Subtraction -, Multiplication *, Division /, Modulo %, and Parentheses ().
  • Output: Use print <expr> to output calculated values to the console.
  • Comments: Lines starting with // are ignored.
