⚡ KScript v2.0 Guide & Reference

KScript is a lightweight, high-performance scripting language with diagnostic analysis and multi-base inspection.

Syntax & Types

  • Variables: Multi-character identifiers (e.g. counter = 10, mask = 0xFF, total_sum = 0).
  • Literals: Decimal (100), Hex (0x1F, 0xFF00), Binary (0b1010), Octal (0o77).
  • Operators: Arithmetic (+, -, *, /, %, **), Bitwise (&, |, ^, ~, <<, >>), Comparison (==, !=, <, <=, >, >=), Logical (&&, ||, !).
  • Built-in Functions: abs(x), min(a,b), max(a,b), clamp(x,lo,hi), sqrt(x), gcd(a,b), fact(n), rand(min,max), hex(x), bin(x).
  • Control Flow: if <cond> ... elif ... else ... endif, while <cond> ... endwhile, loop <n> ... endloop.
  • Console: print "Label:", expr1, expr2.
  • Comments: // This is a line comment.
