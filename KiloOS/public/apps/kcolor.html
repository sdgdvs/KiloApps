🎨 KColor Quick Guide & Shortcuts

Features & Tools:

  • Precision RGB, HSL, HSV, and CMYK interactive sliders with dynamic color tracks
  • Universal input accepting HEX, RGB, HSL, HSV, CMYK, CSS Vars, and named colors
  • Real-time WCAG 2.1 AA/AAA contrast ratios against white & dark text
  • Harmonies generator (Complementary, Analogous, Triadic, Tetradic)
  • 9-step dynamic Tints & Shades scale
  • Palette library with localStorage persistence, CSS/JSON export, and right-click removal
  • Previous / current color comparison with one-click revert

Keyboard Shortcuts:

  • F1, H, or ? — Open this Help guide
  • F5 / Ctrl+S — Quicksave palette & active color
  • F9 / Ctrl+O — Quickload saved state
  • R — Generate random color
  • I — Invert active color
  • C — Copy active HEX code
  • 1–9 — Quick-select palette swatches 1–9
  • Esc / Enter — Close modal / blur inputs / dismiss toast
