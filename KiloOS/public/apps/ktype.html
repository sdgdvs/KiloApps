Help & Controls

Hotkeys
  • F1 or H: Toggle this help guide
  • F5: Quicksave workspace snapshot to localStorage
  • F9: Quickload restored workspace snapshot
  • Esc: Restart current test or arcade game / dismiss modals
  • Backspace: Delete previous character
  • Space: Submit current word (or restart when Game Over)
  • Enter: Confirm actions or restart game
  • 🏁 Typing Duel: Live online multiplayer speed racing via Firebase RTDB or local AI rivals
