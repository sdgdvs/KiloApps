📊 KChart Studio — User Guide & Controls
📊 1. Visualization Modes

Switch between 6 distinct visualization rendering engines: Bar Chart [1], Line Graph [2], Area Gradient [3], Pie Chart [4], Doughnut Chart [5], and multi-axial Radar / Spider Chart [6]. Hover over any bar, point, slice, or vertex to inspect precise values in the interactive HUD tooltip.

📈 2. Trendlines & Regression Analysis

Overlay mathematical and statistical regressions onto cartesian charts (Press 'T' to cycle):

  • Linear Fit: Ordinary Least Squares ($y = mx + b$) regression with live slope and $R^2$ goodness-of-fit.
  • Moving Average: 3-point rolling window smoothed trend curve.
  • Mean Line: Arithmetic dataset mean baseline reference.

🧮 3. Statistical Analysis Suite

Real-time metrics compute automatically: Count, Total Sum, Mean, Median, Standard Deviation, Min / Max Extrema, Slope ($m$), and $R^2$ Fit.

📁 4. Import, Export & Customization

Easily drag and drop CSV or JSON datasets directly onto the workspace. Export high-resolution vector SVG (scalable for publication), raster PNG, clean CSV tables, or JSON structures with one click.
