KPass Help & Shortcuts

Generator: Customize length (8-64) & character sets, then click Generate or press Enter. Click the password text to quickly copy it.

Vault: View, copy, search, categorize, and safely store credentials encrypted locally with AES-GCM 256.

Auto-Lock: For your protection, the vault auto-locks after 1 minute of inactivity.

Backup: Easily export or restore credentials using CSV or JSON formats.

Shortcuts:
• '1' / '2' = Switch Tabs | 'H' or F1 = Toggle Help | Esc = Close Modals / Clear Search
• Enter = Unlock / Save / Generate | Ctrl+F or '/' = Focus Search
• Ctrl+S = Save Credential | Ctrl+G = Generate | Ctrl+C or 'C' = Copy Password
• Alt+L = Lock Vault | Alt+J = Export JSON | Alt+E = Export CSV | Alt+I = Import File
