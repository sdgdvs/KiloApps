1. LSB Steganography Principles

In 24-bit RGB images, each pixel consists of 8 bits per channel (Red, Green, Blue). Modifying the least significant bit (LSB) changes pixel luminosity by at most 1/256th (0.39%), remaining completely imperceptible to the human eye while yielding up to 73.7 KB of secret storage on a 512x384 canvas.

2. Seeded PRNG Pixel Dispersion

Naive steganography writes bits sequentially from (0,0), creating obvious rectangular bitplane artifacts detectable in an image editor. KSteno uses a password-seeded Linear Congruential Generator (LCG) to disperse bits pseudo-randomly across the entire coordinate space, defeating sequential visual inspection.

3. Chi-Square (χ²) Steganalysis

The Westfeld-Pfitzmann detector tests theoretical equilibrium between Pairs of Values (2k and 2k+1). Natural photographic gradients have unequal frequencies. Random bit injection equalizes these pairs. When χ² probability approaches 100%, payload presence is statistically proven.
