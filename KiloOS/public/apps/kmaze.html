🛡️ KMaze - Tactical Dungeon Descent Guide

🎮 Movement & Navigation

W / ↑ : Move Forward
S / ↓ : Move Backward
A / ← : Turn Left
D / → : Turn Right
Shift : Sprint Run
X / Ctrl : Stealth Crouch (Silence Footsteps)
Space / Enter : Start / Proceed

⚔️ Active Relics & Abilities

P : Pickaxe (Cleave walls, secrets, minotaurs)
C : Pathfinder (Draws path to key & exit, 10s)
S / B : Speed Shoes (Double velocity, 8s)
F : Stun Spray (Freezes minotaurs, 10s)
T : Time Freeze (Halts dungeon entities, 10s)
V / L : Save / Load Checkpoint

🗺️ Labyrinth Codex

Green Portal [2]: Exit to next descent level
Cyan Stairwell [38]: Sublevel descent shaft
Gold Key [3] & Blue Door [4]: Gate
Save Shrine [28]: Restores items & saves progress
Wall Torch [29]: Illuminates dark catacombs (15s)
Illusion Wall [39]: Secret breakable phantom wall
Lore Tablet [40]: Ancient wisdom & relic drops

💀 Dangers & Combat

Lava [6] & Spikes [25]: Traps (Crouch cushions -50%!)
Minotaur Monster [12]: Hunts by footstep sound
Minotaur Overlord [15]: Boss guarding floor 45
💡 Tactical Tip: Crouch with X to sneak past minotaurs undetected! Strike them with P (Pickaxe) or freeze with F.
