Welcome to KTask Monitor

        

        
      

      

        

          KTask is the retro-modern process manager and diagnostic suite for KiloOS. Monitor active system processes, inspect loaded modules, and analyze system performance in real time.
        

        

          
⚡ Interactive Inspector: Double-click any task or press Enter / I to view active threads, loaded DLLs, memory map segments, and live hex headers.

          
🎮 Keyboard Navigation: Use ↑ / ↓ to select tasks, P to adjust scheduling priority, and Del to terminate a process.

          
💾 Quicksave & Persistence: Press F5 to capture a local snapshot of all active processes, and F9 to reload it at any time.

          
📊 Exports & Imports: Export snapshots to CSV (E) or JSON (J), or import saved process lists using the Import button.
