Welcome to KTask Monitor

        

        
      

      

        

          KTask is the retro-modern process manager and diagnostic suite for KiloOS.
        

        

          
🌲 Process Tree Hierarchy: Press T or click Tree to inspect parent-child execution lineages.

          
⚡ Interactive Inspector: Press I or Enter to inspect threads, modules, memory maps, ASCII memory string search, environment variables, and CPU affinity.

          
⚙️ CPU Core Affinity: Press A to cycle CPU affinity masks across 8 logical processor cores.

          
📊 Exports & Reports: Export snapshots to CSV (E), JSON (J), or Markdown Diagnostic Audit Reports (M).
