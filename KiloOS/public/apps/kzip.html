KZip Archiver Studio - Help & Shortcuts

Container Formats & Compression:

  • KZA: Micro-archiver format with RLE, Store, and password cipher.
  • ZIP: Standard PKZIP 2.0 container compatible with Windows/WinZip/7-Zip.
  • TAR: Standard POSIX ustar tape archive format.

Archive Operations:

  • Open [Ctrl+O]: Load .kza, .zip, or .tar archive.
  • Add File [Ctrl+N]: Add files to archive (or drag & drop).
  • New File [Alt+N]: Create new text file directly inside archive.
  • Edit File [E]: In-archive text editor for documents and code.
  • Rename [F2]: Rename selected file in archive.
  • Remove [Del]: Remove selected files.
  • Pack [Ctrl+S]: Compress and download archive (.kza, .zip, .tar).
  • Extract Selected [X]: Extract selected files to disk.
  • Extract All [Ctrl+E]: Extract all files to disk.
  • Batch Extract [B]: Unpack multiple archives in batch.
  • Verify CRC32 [V]: Test data checksums against corruption.
  • Preview [P or Enter]: Deep hex inspector, chunk view, and entropy.
  • Analysis [Alt+A]: Shannon entropy and compression diagnostics.
  • Manifest [Ctrl+M]: Generate inventory report (CSV, JSON, ASCII).
  • Save State [F5]: Quicksave full archive workspace snapshot.
  • Load State [F9]: Restore quicksaved archive workspace snapshot.
  • Sound [M]: Toggle procedural Genesis/SNES audio synthesizer.
  • Demo [D]: Load sample files bundle.

Keyboard Accelerators:

  • F1 / H: Toggle Help dialog
  • F2: Rename selected file
  • F5 / F9: Quicksave / Quickload workspace
  • Ctrl+O / Ctrl+S: Open / Pack archive
  • Ctrl+N / Alt+N: Add file / New text file
  • Ctrl+E / X: Extract all / Extract selected
  • Ctrl+M / Alt+A: Inventory manifest / Entropy analysis
  • E / P / V / B / D / M: Edit / Preview / Verify / Batch / Demo / Sound
  • Delete: Remove selected file
  • Escape: Close active modal or clear search
