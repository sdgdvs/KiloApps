💣 KMine - Rules & Keyboard Shortcuts

Objective: Uncover all safe tiles across the grid without detonating any hidden naval mines. Numbers indicate how many adjacent mines touch that tile.

🖱️ Mouse & Touch Controls
  • Left-Click / Tap: Reveal tile (safe first click guaranteed; places flag if in Flag Mode)
  • Right-Click / Long-Press (Hold): Place or remove mine flag 🚩 (with haptic feedback on touch)
  • Left-Click on Revealed Number: Chord — instantly reveals all adjacent unflagged tiles if placed flags match the number! Hovering a number previews the chord target area.
  • Mode Button / F: Switch between ⛏️ Dig Mode and 🚩 Flag Mode (ideal for touchscreens)
