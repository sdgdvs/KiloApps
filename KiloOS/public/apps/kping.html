KPing Reference & Keyboard Shortcuts
Path MTU Discovery (PMTU): Probes destination buffer sizes with the Don't-Fragment (DF) bit set to determine maximum transmission unit without IP fragmentation, calculating recommended TCP MSS (MTU - 40B).
Shortcut Action Description
Enter / P Ping Send ICMP echo requests to measure latency & jitter
T Trace Trace router hops along the destination path
M MTU Sweep Perform Path MTU Discovery with DF bit sweep
E / Ctrl+S Export Save session logs & latency telemetry to JSON file
C Clear Clear terminal output console & telemetry graph
1 - 6 Presets Quickly select Localhost, Cloudflare, Google DNS, etc.
Esc Cancel / Close Stop active operation, close modal or dismiss notification
F1 / H Help Open this interactive diagnostics manual
