KPing Reference & Diagnostic Shortcuts
Diagnostic Suite Modes:
• Ping [P]: Precision ICMP echo testing measuring latency, jitter (RFC 3550), std deviation, VoIP MOS, and SLA compliance.
• Trace [T]: Hop-by-hop route latency and transit mapping.
• PMTU [M]: Path MTU Discovery sweep probing Don't-Fragment buffer limits to compute recommended TCP MSS.
• Subnet [S]: Fast CIDR LAN discovery sweep scanning active nodes on the local subnet.
• DNS [D]: Reverse PTR resolution and RFC IP classification (RFC 1918, RFC 1122, RFC 3927, CGNAT).
• BGP [B]: Autonomous System transit path inspector (AS701 UUNET, AS3561 MCI, AS1239 SprintLink).
• Bufferbloat [Q]: RFC 8290 AQM audit evaluating unloaded vs loaded delay, buffer bloat grade, and TCP BDP.
• Global Mesh [G]: Real-time cross-computer peer echo via Firebase Realtime Database.
