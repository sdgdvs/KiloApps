How to Play KSimon 3D

Rules: Watch the sequence of LED buttons & pitch tones and repeat it back. The sequence grows each round.

Controls:

  • Mouse / Touch: Click or tap the 3D console buttons.
  • Keyboard: Q, W, E, R (Top Row) / A, S, D, F (Bottom Row) or 1-8 keys (customizable in Controls).
  • Space: Start game.
  • H: Hint (Replays current sequence at slow speed).
  • L: Slow-Mo (Halves playback speed for stage).
  • B / J: Strike Shield Status (Passive: auto-absorbs 1 mistake or timeout).
  • T / F: Time Freeze (Pauses stage input countdown).
  • F5 / F9: Quick Save / Quick Load.
  • Esc / Click Outside: Dismiss Help.

Modes:

  • 4-Button / 6-Button / 8-Button: Progressive button layout grid challenges.
  • Chaos Reverse: Unpredictable pitch tones & reverse input order!
  • Pitch Audio: Sound-only mode without color hints!
  • Speed: Ultra fast playback and 10s countdown timer.
  • Campaign: 20 stages culminating in Stage 20 Grandmaster Memory Master Challenge!
  • 🌐 Online Multiplayer: Real-time cross-computer Speed Matches & Add-A-Step Volley Duels via Subnet RFMS!
