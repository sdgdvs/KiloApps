    KNote - User Manual & Shortcuts

    KNote is a retro-cybernetic personal notepad featuring multi-tab sessions, tagging, Web Crypto AES-GCM encryption, and multi-format data interoperability.

    Ctrl + NCreate new note / open tab
    Ctrl + WClose active tab
    Ctrl + TabCycle through open tabs
    Ctrl + 1..9Switch directly to tab 1-9
    Ctrl + FSearch notes list & #tags
    Ctrl + HOpen in-editor Find & Replace
    Ctrl + B / IFormat selected text Bold / Italic
    Alt + DInsert current timestamp
    Ctrl + PPin / Unpin current note
    Ctrl + EToggle Markdown Preview
    Ctrl + SSave notes immediately
    Ctrl + DMove note to Trash (instant Undo)
    TabIndent 2 spaces (Shift+Tab to dedent)
    F1 or HOpen this Help manual
    EscClose dialogs, find bar, or clear search

    Features & Data Interoperability:
    • Multi-Tab Sessions: Open and edit multiple notes simultaneously in tabbed workspace.
    • Tag Cloud: Type #tagname anywhere to tag. Filter instantly via clickable tag chips.
    • Spreadsheet & Dossier Export: Export all notes as CSV table, print-ready HTML dossier, master Markdown notebook digest, or complete JSON backup.
    • Universal Importer: Import notes from JSON arrays, CSV spreadsheets, Markdown, or text files.
    • AES-GCM Encryption: Lock sensitive notes with authenticated Web Crypto AES-GCM (256-bit).
    • Trash & Recovery: Deleted notes are held in the Trash bin with one-click restoration.
