    KNote - User Manual & Shortcuts

    KNote is a lightweight, high-speed personal notepad with tagging, AES encryption, and multi-format export.

    Ctrl + NCreate new note
    Ctrl + FSearch notes & tags
    Ctrl + PPin / Unpin current note
    Ctrl + EToggle Markdown Preview
    Ctrl + SSave notes immediately
    Ctrl + DDelete current note
    TabIndent 2 spaces in editor (Shift+Tab to dedent)
    F1 or HOpen this Help manual
    ↑ / ↓ in listNavigate between notes
    Enter in listOpen selected note
    Delete in listDelete selected note
    EscClose dialogs, toast, or clear search

    Features:
    • Tags: Type #tagname anywhere in your note to tag it. Filter notes by typing #tag in the search bar.
    • AES Encryption: Click 🔒 Lock to password-protect sensitive notes with Web Crypto AES-GCM.
    • Backups: Export or Import all notes using standard JSON files.
