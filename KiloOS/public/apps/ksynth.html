Synthesizer Controls & Shortcuts
  • [Space] / [P] : Play / Pause 16-step pattern sequencer
  • [1] - [9], [0] : Switch to Preset 1-10 (Lead, Bass, Pad, Chiptune, Bell, Pluck, YM2612 FM, SPC700, Beacon, Juno)
  • [Shift+J] / [N] : Join / Leave Live Collaborative Jam Session
  • [Shift+G] : Toggle Subnet Ghost Jammer (Rule 12 Autonomous AI Jam Bot)
  • [O] : Toggle Vintage Analog Overdrive / Distortion
  • [Shift+F] : Toggle LFO Modulation Matrix
  • [Shift+M] : Export 16-Step Pattern as Standard MIDI File (.mid)
  • [M] : Toggle Yamaha YM2612 2-Operator FM Synthesis Mode
  • [Z] / [X] / [◄] / [►] : Shift keyboard octave down / up (-2 to +2)
  • [▲] / [▼] : Adjust Master Volume (+5% / -5%)
  • [Enter] : Preview synth patch chord
  • [L] : Toggle Arpeggiator Latch (Hold notes)
  • [C] : Clear active 16-step sequencer
  • [R] : Randomize sequencer pattern notes
  • [F5] / [F9] : Quicksave / Quickload entire synth workstation state
  • [Ctrl+S] : Export synth patch preset as JSON
  • [Ctrl+O] : Import synth patch preset JSON
  • [Ctrl+E] : Export 16-bit 44.1 kHz WAV audio preview
  • [Esc] : Stop all voices (Panic) / Close modal guides
  • [F1] / [?] : Toggle this Help guide
Audio Engine & Jam Features
  • • Dual Synthesis Engines: Subtractive 5-waveform dual-oscillator & Yamaha YM2612 2-Op FM synthesis.
  • • LFO Modulation Matrix: Sine, Triangle, Saw, Square, and Sample & Hold with Free Hz or Tempo Sync.
  • • Drive, Bitcrush & Chorus: Vintage analog saturation, tone filter, 4-16 bit DAC crunch, and Roland Juno stereo ensemble.
  • • Standardized RFMS Multiplayer: Real-time jam rooms via Firebase RTDB, room link sharing (#room=CODE), and 25-second Subnet Ghost Jammer fallback.
  • • Standard MIDI Export: Type 0 SMF .mid generator for direct DAW interoperability.
  • • SPC700 Delay Echo: Stereo ping-pong delay unit with warm Gaussian feedback loop damping.
  • • ADSR Envelope: Real-time visual curve canvas with millisecond precision.
