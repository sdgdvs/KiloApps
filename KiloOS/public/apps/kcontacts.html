📇 KContacts User Guide & Shortcuts
  • F1 or H : Open / close this help guide
  • Esc : Close modals, unfocus inputs, or clear search
  • 1 - 7 : Quick switch categories (1=All, 2=Favs, 3=Work, 4=Personal, etc.)
  • Ctrl+S : Save contact details
  • N or Ctrl+N : Create new contact draft
  • C : Quick copy contact info to clipboard
  • Alt+C : Call selected contact phone
  • Alt+M : Email selected contact
  • Ctrl+M : Merge duplicate contacts
  • Ctrl+E : Export directory (.md, .json, .vcf, .csv, .ldif)
  • Ctrl+I : Import contacts file
  • / or Ctrl+F : Focus search input
  • ↑ / ↓ : Navigate through contact list
  • Delete : Delete selected contact
Advanced Capabilities:
• Extended Schema: Physical street addresses, website links, birthdays with zodiac/age/countdown, and custom key-value attributes.
• Multi-Select Batch Actions: Click '☑️ Select' to batch-tag, categorize, export, or delete contacts.
• Print Engine: Print 3x5 Rolodex index cards, Avery 5160 mailing labels, or phonebook directories.
• Interoperability: Import and export LDIF (Netscape Communicator standard), vCard 3.0, CSV, and JSON.
• Sorting: Sort by Name, Company, Category, Birthday proximity, or recency.
