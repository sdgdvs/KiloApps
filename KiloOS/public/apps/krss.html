📡 Supported Syndication Protocols
• RSS 0.91 & 2.0: Standard XML channel format with <item> nodes.
• RSS 1.0 (RDF): Dublin Core metadata and RDF item nodes.
• Atom 1.0: IETF RFC 4287 standard with <entry> and <summary> nodes.
• JSON Feed 1.1: Modern jsonfeed.org format with full round-trip export.
• OPML 2.0: Outlines format for subscription aggregation and export.
• KiloNet Live Wire: Real-time global syndication mesh over Firebase RTDB.
