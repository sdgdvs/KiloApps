🛡️ Algorithm Reference
• CRC32: IEEE 802.3 32-bit cyclic redundancy check. Standard for ZIP/SFV transfers.
• Adler-32: 32-bit zlib checksum optimizing speed over dispersion.
• FNV-1a: Fowler–Noll–Vo non-cryptographic fast hash with high dispersion.
• MD5: RFC 1321 128-bit digest. Legacy fingerprinting and integrity verification.
• SHA-1: NIST 160-bit digest. Common in legacy Git and SSL manifests.
• SHA-256 / SHA-512: NIST FIPS PUB 180-4 cryptographic standard. Collision-resistant.
