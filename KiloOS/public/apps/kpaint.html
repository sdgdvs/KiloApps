Drawing & Features
  • Retro Firebase Multiplayer (RFMS): Join shared studio rooms (e.g. KPT-4892) powered by Firebase RTDB. Paint simultaneously with friends across computers with real-time brush strokes, floating peer cursors, quick chat, and snapshot sync!
  • Sprite Reel Animation & Onion Skinning: Multi-frame pixel art flipbook engine [F]! Add/duplicate/delete frames, animate at 1-24 FPS with looping playback, preview ghosts of previous frames with translucent cyan onion skinning, and export complete horizontal Sprite Sheets!
  • Bezier Curve & Color Replace Tools: 3-point Bezier curve tool [K] (drag line then bend curve) and global layer color replacement tool [Shift+G] for rapid pixel palette shifts!
  • Rule 12 Subnet Ghost Artist: If waiting for a peer and none joins within 25 seconds, the Subnet Ghost Artist (AI Cyber-Painter Copilot) automatically engages to collaboratively sketch alongside you!
  • Dual Color Palette (FG & BG): Left-click draws with Foreground; right-click draws with Background. Press X to instantly swap colors. Right-click any palette swatch to set Background color.
  • Linear & Radial Gradient Tool: Drag vector line to paint smooth/dithered gradients between Foreground and Background colors. Hold Shift for radial gradient. Press J.
  • Toggleable Pixel Grid: Crisp 1px pixel grid aligning canvas pixels when zoomed in (≥200%). Press Ctrl+G or click Grid.
  • Universal Retro Audio: Sega Genesis Yamaha YM2612 2-operator FM synthesis and Super Nintendo SPC700 stereo delay DSP. Press U to toggle.
  • Retro Dithering & Vintage Filters: Authentic Floyd-Steinberg error diffusion for Amiga OCS 32-Color, 1-Bit, 16-color PC VGA, Game Boy DMG-01 green, Commodore 64, CGA Mode 1, 8px Mosaic, Sabattier Solarization, RGB Beam Split, and CRT Phosphor Bloom!
  • Symmetry & Text Stamping: Instant horizontal, vertical, or 4-way kaleidoscope mirroring [M] and crisp typography stamps [T].
  • Deep Retro Format Support: Export to 24-bit TrueColor RLE PCX (ZSoft Paintbrush), Windows Icon (.ICO 16x16/32x32/48x48), ANSI Art BBS (.ANS / .TXT), XBM X11 Bitmap (.xbm), PNG, WEBP, 24-bit BMP, PPM (Netpbm), C Header (.h), SVG Vector, JSON Sprite, Standalone HTML5 Canvas Page, and GIMP Palette (.gpl)!
