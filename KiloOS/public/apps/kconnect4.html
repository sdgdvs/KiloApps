KConnect4 - Help & Controls

Rules: Connect 4 discs vertically, horizontally, or diagonally!

Game Modes: vs AI, 2-Player Local, 20-Stage Campaign (7x6 to 10x8), and Speed Blitz.

Controls & Hotkeys:

  • [1-7] / Numpad / Click: Drop piece in column
  • [B] Bomb: Explodes 3x3 surrounding cells
  • [D] Drill: Crushes cell directly underneath
  • [M] Magnet: Pulls friendly discs from adjacent columns
  • [F] Freeze: Freezes selected column for 2 turns
  • [T] AI Hint: Highlights recommended column
  • [C] Radar: Toggles real-time tactical threat radar per column
  • [U] Undo: Reverts last turn pair
  • [V] Mode: Cycles game mode
  • [O] Online: Open multiplayer lobby & room browser
  • [N] Notation: View C4N move sequence, FEN, & interactive ply scrubbing
  • [R] Reset / Rematch: Restart board or ask online rematch
  • [P] Mute: Toggle sound effects (Genesis YM2612 2-Op FM audio)
  • [F5 / Ctrl+S] Save: Quick-save game state
  • [F9 / Ctrl+O] Load: Quick-load saved game
  • [Esc]: Close dialogs / cancel skill selection
