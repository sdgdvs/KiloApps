Features & Security

• Column Sorting: Click any header (ID, Name, Dept, Role) to toggle ascending/descending order.
• Encryption: Type an Encryption Key in the password box to encrypt LocalStorage and JSON exports with XOR-based cipher.
• Capacity: Max storage capacity is 500 records.
