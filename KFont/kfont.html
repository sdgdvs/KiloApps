        KFont Typography Inspector Help
        
      

      
A comprehensive engineering workstation for inspecting font measurements, Unicode blocks, kerning behavior, vector guidelines, optical scaling, WCAG contrast, and code generation.

      
    
        
  • Metrics & OS/2: Font bounding box, typographic ascender/descender, and Panose classification.
    • 
        
  • Unicode Ranges: 14 Unicode blocks with glyph cards (click any glyph to dissect in Anatomy).
    • 
        
  • Kerning & Hinting: Visual kerning analysis with custom pair tester and rasterization ladder.
    • 
        
  • Glyph Anatomy: Vector guidelines, ABC spacing, bearings, and multi-encoding codec dissector.
    • 
        
  • Type Waterfall: Modular scale optical ladder from 9px to 72px with advance widths.
    • 
        
  • Contrast & WCAG: 6 retro and modern palettes with real-time luminance contrast ratios.
    • 
        
  • Spec & Code Export: Win32 GDI C LOGFONT code and CSS typography variables generator.
    • 
        
  • Live Sample & Run: Real-time text sandbox with granular character advance dissector table.
    •
